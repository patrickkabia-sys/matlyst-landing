Move your recipe collection

Import your Paprika recipes into Matlyst

You do not need to rebuild your recipe collection by hand. Export it from Paprika, open the file in Matlyst and choose the recipes you want to bring with you.

How to move recipes from Paprika

Keep a copy of your original export until you have checked the imported recipes. Matlyst reads the file you select and shows the recipes before they are saved to your collection.

  1. Export from Paprika. Select the recipes you want to move and export them in Paprika format. This normally creates a .paprikarecipes file.
  2. Open the file in Matlyst. In Matlyst, open Settings, find the import section and choose the option for moving recipes from another app. Select the exported file.
  3. Choose and import. Matlyst analyses the file and shows the recipes it found. Select the recipes you want, import them and review the result.

Matlyst accepts .paprikarecipe, .paprikarecipes and compatible .zip files. You can also open a supported export file from the Files app and share it with Matlyst.

A file can contain up to 300 recipes and must be no larger than 25 MB. Split a larger collection into smaller exports. File imports use your available import allowance; Matlyst shows the current limit before an upgrade is required.

What Matlyst can bring across

Matlyst preserves recognised recipe titles, descriptions, ingredients, instructions, servings, cooking times, tags, source links, ratings, images and Paprika categories. Categories become folders when they can be read. Check the result because damaged or unusual export data may be skipped.

After the move

Your imported recipes become part of the same searchable collection as recipes from Instagram, TikTok, YouTube, websites, photos and text. You can organise them, add them to your meal plan and send ingredients to your shopping list.

An independent file import

The transfer uses an export file you choose. Matlyst does not ask for your Paprika login and is not affiliated with Paprika. Paprika and related names belong to their respective owners.

See the complete recipe import guide for other supported sources.

Paprika import questions

Can I import my recipes from Paprika?

Yes. Export the recipes from Paprika, select the file in Matlyst and choose which recognised recipes to import.

Which Paprika files does Matlyst support?

Matlyst accepts .paprikarecipe, .paprikarecipes and compatible .zip files up to 25 MB. A single import can contain up to 300 recipes.

Do my Paprika folders come across?

Paprika categories are recreated as Matlyst folders when they can be read from the export. Review the imported collection afterwards because unusual or damaged data may be skipped.

Are recipe images imported from Paprika?

Matlyst imports valid images included in supported Paprika exports. If an image is missing or invalid, the recipe can still be imported without it.

Does Matlyst need my Paprika password?

No. The import uses the export file you choose. Matlyst does not connect to your Paprika account or ask for your Paprika login.
